# Trivanta Voyages

A responsive travel and tourism website designed to showcase holiday packages, destinations, and booking information. The project is built using plain HTML, CSS, and JavaScript, making it lightweight, easy to run, and simple to customize.

## Overview

Trivanta Voyages is a static tours and travel website that allows users to:

- Explore featured destinations
- View package details and pricing
- Learn more about the company
- Contact the travel team
- Book a trip through the website

The site includes multiple destination pages, a modern home page, and visually appealing travel-themed content built with a clean user interface.

## Features

- Attractive travel landing page with banner and hero section
- Responsive design for desktop and mobile devices
- Destination-specific pages for popular countries
- Package cards with pricing and trip details
- About Us and Contact Us pages
- Booking page for user reservations
- Smooth scroll-based animations
- Lightweight static frontend setup

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome for icons
- AOS (Animate On Scroll) library

## How to Run

### Option 1: Open directly in the browser

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` to view the website in a browser.

### Option 2: Run with a local web server

```bash
cd Trivanta-Voyages
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customization

You can easily customize the website by:

- Modifying text in `index.html`
- Updating travel packages and prices
- Changing colors, spacing, and layout in `style.css`
- Replacing images in the root folder with your own assets
- Updating contact details in the footer and contact page
